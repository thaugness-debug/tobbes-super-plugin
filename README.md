# Tobbe's Super Plugin

En lilla wavetable-synth for FL Studio, bygget på den åpne kildekoden til
Matt Tytels synth (https://github.com/mtytel/vital). Dette er et uoffisielt
prosjekt uten tilknytning til originalen.

## Lisens
GPLv3 – se LICENSE. Kildekoden må forbli åpen.

## Bygging
Hver push bygger en Windows-VST3 via GitHub Actions (fanen *Actions* →
siste kjøring → *Artifacts*). Legg `.vst3`-filen i
`C:\Program Files\Common Files\VST3`.
